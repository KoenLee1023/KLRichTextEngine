# 예제

저장소에는 로컬 Swift Package를 사용하는 독립적인 iOS demo 세 개가 있습니다.

- `Examples/Composer`는 `RichTextEditor`로 편집하고 `RichTextDocumentCodec`으로 버전이 있는 JSON을 내보냅니다.
- `Examples/InteractiveReader`는 `RichTextViewer`로 표시하고 `RichTextChecklistMutation`으로 체크 항목을 변경합니다.
- `Examples/MigrationLab`은 정상, 알 수 없는 입력, 손상된 입력을 읽고 접근 상태를 보여줍니다.

예제 데이터는 합성 데이터이며 패키지 경계를 설명하는 용도입니다.
