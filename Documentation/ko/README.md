# KLRichTextEngine

> [English](../../README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](README.md)

KLRichTextEngine은 문서 구조를 잃지 않고 리치 텍스트를 저장하고 편집하는 패키지입니다. Codable 문서 모델, AttributedString 변환, 체크리스트 편집, 글꼴 의도, 붙여넣기 정규화, SwiftUI 편집기와 뷰어를 제공합니다.

이 디렉터리에는 한국어 시작 가이드, API, 아키텍처, 예제 및 마이그레이션 문서가 있습니다.
