# KLRichTextEngine

> [English](../../README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)

KLRichTextEngine 用於保存及編輯富文字，同時保留文件結構。它提供可編碼的文件模型、AttributedString 轉換、清單編輯、字體意圖、貼上規範化，以及 SwiftUI 編輯器和閱讀視圖。

本目錄提供繁體中文的入門、API、架構、範例及遷移文件。
