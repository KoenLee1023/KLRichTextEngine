# 範例

倉庫包含三個獨立的 iOS demo，皆透過 Swift Package Manager 使用本地套件。

- `Examples/Composer` 使用 `RichTextEditor` 編輯文件，並以 `RichTextDocumentCodec` 匯出版本化 JSON。
- `Examples/InteractiveReader` 使用 `RichTextViewer` 顯示可選取內容，並以 `RichTextChecklistMutation` 切換清單。
- `Examples/MigrationLab` 載入正常、未知及損壞的輸入，顯示對應的存取狀態。

範例使用合成資料，只用於說明套件邊界。
