# KLRichTextEngine

> [English](../../README.md) · [简体中文](README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)

KLRichTextEngine 用于保存和编辑富文本，同时保留文档结构。它提供可编码的文档模型、AttributedString 转换、清单编辑、字体意图、粘贴规范化，以及 SwiftUI 编辑器和阅读视图。
