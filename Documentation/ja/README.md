# KLRichTextEngine

> [English](../../README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](README.md) · [한국어](../ko/README.md)

KLRichTextEngine は、文書構造を失わずにリッチテキストを保存・編集するためのパッケージです。Codable の文書モデル、AttributedString との変換、チェックリストの編集、フォント意図、ペーストの正規化、SwiftUI の編集・表示ビューを提供します。
