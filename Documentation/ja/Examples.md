# サンプル

リポジトリには、ローカルの Swift Package を利用する独立した iOS demo が三つあります。

- `Examples/Composer` は `RichTextEditor` で編集し、`RichTextDocumentCodec` で JSON を書き出します。
- `Examples/InteractiveReader` は `RichTextViewer` で表示し、`RichTextChecklistMutation` でチェック項目を変更します。
- `Examples/MigrationLab` は正常、未知、破損した入力を読み込み、アクセス状態を表示します。

サンプルのデータは合成データです。
